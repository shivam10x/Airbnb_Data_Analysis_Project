# Airbnb_Data_Analysis_Project

## Overview

This project focuses on analyzing Airbnb listing data to uncover insights about pricing, availability, and location trends. Using Python and data visualization techniques, the goal is to understand factors affecting Airbnb prices and customer preferences.

---

## 🎯 Objectives

* Analyze Airbnb listing prices across different locations
* Identify factors affecting pricing (room type, location, availability)
* Visualize trends using charts and graphs
* Generate insights for better decision-making

---

## 🛠️ Tools & Technologies

* Python 🐍
* Pandas
* Matplotlib
* Jupyter Notebook

## 📊 Data Analysis Steps

1. Data Cleaning

   * Handling missing values
   * Removing duplicates
   * Formatting columns

2. Exploratory Data Analysis (EDA)

   * Price distribution analysis
   * Room type comparison
   * Location-based insights

3. Data Visualization

   * Histogram of prices
   * Bar charts for room types
   * Scatter plots for location vs price

---

## 📈 Sample Visualizations

* 📊 Price Distribution using Histogram
* 🏠 Room Type vs Average Price (Bar Chart)
* 📍 Location vs Price (Scatter Plot)

---

## 🔍 Key Insights

* Entire homes/apartments are more expensive than private rooms
* Prices vary significantly by location
* Higher availability often leads to competitive pricing
